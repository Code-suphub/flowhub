# 菜单栏显隐：光标与闪现优化验证

验证日期：2026-09-05。安装版本：`0.1.5-local.20260905113958`。

## 本轮修改

- 单图标移动不再展开普通隐藏分界和始终隐藏分界，避免主动露出整个隐藏区。
- 在 Session 事件监听点确认事件到达后，再向图标所属进程投递，避免异步投递竞争。
- 按下事件使用桌面外的起点和明确的窗口目标，避免负坐标落到 Apple 菜单。
- 移动期间短暂隐藏光标；同步恢复位置后再显示。不再用异步 MouseMoved 事件恢复位置。
- 恢复光标后被动等待分界动画结束，避免已移动成功却被误判失败、反复拖动。
- 事件超时会补发释放事件；作用域退出时恢复光标。不使用输入锁定或鼠标与光标解绑。

## 仍需区分的限制

这不是完全不操作鼠标的原生显隐接口：底层仍发送模拟事件，光标位置在短暂隐藏期间会改变再恢复。本轮优化的是可见跳动、整区展开和重复拖动。

静态截图和前后窗口记录不能证明每一帧都没有闪现；本轮未完成高速录屏验证，也未覆盖多显示器、持续移动鼠标时的并发操作和整体收起状态的完整回归。不能把以上结果表述为“彻底零闪现、零鼠标操作”。
