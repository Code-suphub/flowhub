# 启动器安装版功能验收清单

状态：待解锁公司 Mac 后实机验证。自动化测试和独立 WKWebView 冒烟不替代本清单；通过后逐项勾选，异常保留时间、场景和复现步骤。

当前安装版本：`0.1.17-local.20261104180644`，已包含搜索结果与预览改造，以及统一官方插件库、检查更新、版本说明、下载与校验进度、失败重试、安装后打开和原启停状态保留。安装位置为 `/Applications/FlowHub.app`，旧应用及数据备份已保留。验收前确认设置中显示这一版本；后续再次安装时更新此处版本，不混用不同安装版的结果。

## 第一轮：唤出、输入和执行

- [ ] 从浏览器、编辑器、Finder 和桌面分别用当前全局快捷键唤出，各重复 5 次；立即输入首个字符，搜索框完整接收，不落入原应用，不需要先点击。
- [ ] 连续执行“输入 → Esc 收起 → 再次唤出”，并测试快速双按快捷键；没有残留窗口、迟到聚焦或输入失效。
- [ ] 中文输入法组合、选字、回车提交时不误打开结果；普通查询中的左右键仍移动光标，⌘K 返回并选中查询。
- [ ] 应用、网页、剪贴板、命令备忘之间切换范围，查询保留且可继续输入；清除按钮和无结果页的恢复操作能返回可搜索状态。
- [ ] 单击结果只选中并预览，悬停其他结果不改变选择；双击、搜索框回车和底部主按钮均只执行一次，目标与预览一致。
- [ ] 打开一个现有应用和一个测试网页：启动器收起，目标实际获得焦点；连续打开或快速重新唤出不会被旧请求再次隐藏。
- [ ] 用可恢复的失效入口验证失败提示：查询与选中项保留，允许重试；仅使用临时入口，不修改日常目录。

## 第二轮：预览、键盘和窗口状态

- [ ] 长文本、长路径、多行命令、图片及文件分别预览；列表行高稳定，详情可以滚动、选取文字，完整复制内容与原文一致。
- [ ] 上下键和常用／最近入口的跨排导航与预览一致；预览的上一条／下一条不执行动作，边界不会进入错误结果。
- [ ] ⌘I 进入预览；Esc 按当前层级关闭菜单、返回搜索或收起窗口；F6／⇧F6 与 Tab 不把焦点留在隐藏或禁用控件中。
- [ ] 固定／取消固定窗口；切换其他应用后重新唤出，输入焦点正确，固定状态符合界面显示。
- [ ] 打开设置后返回启动器，检查版本标记、深浅主题、搜索和快捷键；不保存无关配置修改。
- [ ] 检查本地版本需要的辅助功能权限状态与设置入口；授权后实际复制／粘贴可用，不把测试工具自身的授权状态当作 FlowHub 的权限状态。
- [ ] 解锁后的首次唤出、切换 Space、全屏浏览器／编辑器下唤出均可直接输入；有双屏时按[多屏验收步骤](../architecture/launcher/launcher-verification.md)补测，不具备的设备条件单独标注。

## 第三轮：剪贴板、工具与数据

仅用临时内容和空白接收窗口进行粘贴，不向聊天、邮件或终端命令行粘贴。

- [ ] 临时文本记录的原格式粘贴和 ⇧回车纯文本粘贴均进入唤出前的接收窗口；复制全文只复制，不意外粘贴或打开应用。
- [ ] 临时图片和文件记录预览正确，粘贴成功；文件名复制不改变原始文件。
- [ ] 临时记录置顶／取消置顶后状态更新；编辑副本时隐藏再唤出保留查询和草稿，Esc 取消不写入，⌘回车只新建一条副本且保留原文。
- [ ] 删除临时记录的取消、Esc、确认各走一遍；只有显式确认才删除，双击确认不重复提交，不删除原始文件。
- [ ] 计算、时间戳、JSON、URL 等工具仍全宽可用；用 `9007199254740993` 检查 JSON 精度。网络工具只查测试目标，端口工具不结束日常服务。
- [ ] 验证一个非敏感测试账户的验证码复制，以及一个已安装插件的打开／返回；不展示或修改密钥、凭证与授权配置。
- [ ] 真实历史连续翻页、快速输入、来回切范围，列表与预览不串项、不回跳；没有明显卡顿或持续增长的空白占位。
- [ ] 完成后检查原目录、备忘和历史仍在；清理自己创建的临时入口与测试记录，恢复测试前的剪贴板内容和窗口固定状态。

## 第四轮：插件市场

- [ ] 主界面仅有“发现／已安装”；首次进入自动读取配置过的来源，搜索名称、ID、功能或来源能找到对应插件，不会每输入一次就访问仓库。
- [ ] 发现页卡片与已安装列表在插件面板内布局正常；切换视图、打开来源设置后关闭，保留搜索词和当前视图，焦点可继续使用。
- [ ] 安装临时测试插件、切换另一版本：确认中能看到插件名、版本和运行权限提醒；取消无安装，确认只安装一次，完成后状态及插件入口更新。
- [ ] 临时插件的启用／停用、更多菜单中的重新加载／卸载均可用；停用项不会被直接重新加载，卸载需要确认。
- [ ] 修改或移除临时来源后自动重读其余来源，新安装操作使用新凭据；移除来源保留已安装插件，不改动日常来源。
- [ ] 用临时不可达来源验证部分失败提示：可用来源仍显示插件；来源设置内能找到问题并重试，不因慢请求切走视图或清空查询。
- [ ] 来源表单、签名公钥、本机位置、确认框在窄面板中可滚动和操作；测试完成后清理临时插件及来源。
- [ ] 首次进入市场能看到官方公开插件库；点击连接后只添加一个统一官方来源，原六个固定目录、自定义来源及公钥保持原样，不自动安装插件。重复进入不重复添加。
- [ ] 官方聚合地址使用不同公钥时报冲突且不覆盖；模拟保存失败后，原来源保留，重试不会重复添加，其他来源插件仍可安装。
- [ ] 按功能与来源组合筛选，搜索可继续缩小范围；清除搜索与筛选恢复结果，输入时不重复请求来源。
- [ ] 点击卡片名称或“查看详情”能阅读完整说明、版本、能力与来源；Escape／返回浏览后焦点回到入口，浏览位置和搜索保留。详情内安装仍先确认，取消不安装。
- [ ] 官方库选择当前设备适用的最高稳定版本，详情正确标明 Apple Silicon／Intel。没有适用安装包时明确提示，刷新不自动升级插件。
- [ ] “已安装”检查更新、筛选可更新项；更高稳定版显示更新，旧版明确回退，预发布版不混入稳定更新。目录失败时显示检查不完整。
- [ ] 安装或更新前确认版本和来源；下载显示实际字节、总长度已知时显示百分比，校验／解包／保存显示对应阶段。等待中不能重复提交。
- [ ] 临时中断下载／使用无效签名后原插件版本、数据和启停状态保留；确认框可以重试，过期候选可以刷新目录后重新选择。
- [ ] 停用插件更新后仍停用；启用插件安装／更新完成可直接打开，并正确切换独立插件工作区。卸载确认明确保留配置与历史。
- [ ] 版本详情显示发布说明、日期与本机／可安装版本；关闭后焦点回到入口。安装成功后若列表刷新失败，只重载列表，不重复安装。
