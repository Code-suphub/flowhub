# 启动器安装版功能验收清单

状态：已开始公司 Mac 实机验收，尚未整体通过。自动化测试和独立 WKWebView 冒烟不替代本清单；通过后逐项勾选，异常保留时间、场景和复现步骤。复合条目只覆盖部分场景时保持未勾选，在验收记录中注明。

当前安装版本：`0.1.17-local.20261105043110`，已包含此前启动器、插件市场、设置搜索、配置审阅和主体导航改造，以及桌面组件异常恢复、页面展示状态记忆、原生玻璃文字可读性、系统显示偏好适配和首次打开设置的焦点修复。安装位置为 `/Applications/FlowHub.app`，旧应用及数据备份已保留。后续再次安装时更新此处版本，不混用不同安装版的结果。

## 第一轮：唤出、输入和执行

- [ ] 从浏览器、编辑器、Finder 和桌面分别用当前全局快捷键唤出，各重复 5 次；立即输入首个字符，搜索框完整接收，不落入原应用，不需要先点击。
- [ ] 连续执行“输入 → Esc 收起 → 再次唤出”，并测试快速双按快捷键；没有残留窗口、迟到聚焦或输入失效。
- [ ] 中文输入法组合、选字、回车提交时不误打开结果；普通查询中的左右键仍移动光标，⌘K 返回并选中查询。
- [ ] 应用、网页、剪贴板、命令备忘之间切换范围，查询保留且可继续输入；清除按钮和无结果页的恢复操作能返回可搜索状态。
- [ ] 单击结果只选中并预览，悬停其他结果不改变选择；双击、搜索框回车和底部主按钮均只执行一次，目标与预览一致。
- [ ] 打开一个现有应用和一个测试网页：启动器收起，目标实际获得焦点；连续打开或快速重新唤出不会被旧请求再次隐藏。
- [ ] 用可恢复的失效入口验证失败提示：查询与选中项保留，允许重试；仅使用临时入口，不修改日常目录。

## 第二轮：预览、键盘和窗口状态

- [ ] 长文本、长路径、多行命令、图片及文件分别预览；列表行高稳定，详情可以滚动、选取文字，完整复制内容与原文一致。
- [ ] 上下键和常用／最近入口的跨排导航与预览一致；预览的上一条／下一条不执行动作，边界不会进入错误结果。
- [ ] ⌘I 进入预览；Esc 按当前层级关闭菜单、返回搜索或收起窗口；F6／⇧F6 与 Tab 不把焦点留在隐藏或禁用控件中。
- [ ] 固定／取消固定窗口；切换其他应用后重新唤出，输入焦点正确，固定状态符合界面显示。
- [ ] 打开设置后返回启动器，检查版本标记、深浅主题、搜索和快捷键；不保存无关配置修改。
- [ ] 检查本地版本需要的辅助功能权限状态与设置入口；授权后实际复制／粘贴可用，不把测试工具自身的授权状态当作 FlowHub 的权限状态。
- [ ] 解锁后的首次唤出、切换 Space、全屏浏览器／编辑器下唤出均可直接输入；有双屏时按[多屏验收步骤](../architecture/launcher/launcher-verification.md)补测，不具备的设备条件单独标注。

## 第三轮：剪贴板、工具与数据

仅用临时内容和空白接收窗口进行粘贴，不向聊天、邮件或终端命令行粘贴。

- [ ] 临时文本记录的原格式粘贴和 ⇧回车纯文本粘贴均进入唤出前的接收窗口；复制全文只复制，不意外粘贴或打开应用。
- [ ] 临时图片和文件记录预览正确，粘贴成功；文件名复制不改变原始文件。
- [ ] 临时记录置顶／取消置顶后状态更新；编辑副本时隐藏再唤出保留查询和草稿，Esc 取消不写入，⌘回车只新建一条副本且保留原文。
- [ ] 删除临时记录的取消、Esc、确认各走一遍；只有显式确认才删除，双击确认不重复提交，不删除原始文件。
- [ ] 计算、时间戳、JSON、URL 等工具仍全宽可用；用 `9007199254740993` 检查 JSON 精度。网络工具只查测试目标，端口工具不结束日常服务。
- [ ] 验证一个非敏感测试账户的验证码复制，以及一个已安装插件的打开／返回；不展示或修改密钥、凭证与授权配置。
- [ ] 真实历史连续翻页、快速输入、来回切范围，列表与预览不串项、不回跳；没有明显卡顿或持续增长的空白占位。
- [ ] 完成后检查原目录、备忘和历史仍在；清理自己创建的临时入口与测试记录，恢复测试前的剪贴板内容和窗口固定状态。

## 第四轮：插件市场

- [ ] 主界面仅有“发现／已安装”；首次进入自动读取配置过的来源，搜索名称、ID、功能或来源能找到对应插件，不会每输入一次就访问仓库。
- [ ] 发现页卡片与已安装列表在插件面板内布局正常；切换视图、打开来源设置后关闭，保留搜索词和当前视图，焦点可继续使用。
- [ ] 安装临时测试插件、切换另一版本：确认中能看到插件名、版本和运行权限提醒；取消无安装，确认只安装一次，完成后状态及插件入口更新。
- [ ] 临时插件的启用／停用、更多菜单中的重新加载／卸载均可用；停用项不会被直接重新加载，卸载需要确认。
- [ ] 修改或移除临时来源后自动重读其余来源，新安装操作使用新凭据；移除来源保留已安装插件，不改动日常来源。
- [ ] 用临时不可达来源验证部分失败提示：可用来源仍显示插件；来源设置内能找到问题并重试，不因慢请求切走视图或清空查询。
- [ ] 来源表单、签名公钥、本机位置、确认框在窄面板中可滚动和操作；测试完成后清理临时插件及来源。
- [ ] 首次进入市场能看到官方公开插件库；点击连接后只添加一个统一官方来源，原六个固定目录、自定义来源及公钥保持原样，不自动安装插件。重复进入不重复添加。
- [ ] 官方聚合地址使用不同公钥时报冲突且不覆盖；模拟保存失败后，原来源保留，重试不会重复添加，其他来源插件仍可安装。
- [ ] 按功能与来源组合筛选，搜索可继续缩小范围；清除搜索与筛选恢复结果，输入时不重复请求来源。
- [ ] 点击卡片名称或“查看详情”能阅读完整说明、版本、能力与来源；Escape／返回浏览后焦点回到入口，浏览位置和搜索保留。详情内安装仍先确认，取消不安装。
- [ ] 官方库选择当前设备适用的最高稳定版本，详情正确标明 Apple Silicon／Intel。没有适用安装包时明确提示，刷新不自动升级插件。
- [ ] “已安装”检查更新、筛选可更新项；更高稳定版显示更新，旧版明确回退，预发布版不混入稳定更新。目录失败时显示检查不完整。
- [ ] 安装或更新前确认版本和来源；下载显示实际字节、总长度已知时显示百分比，校验／解包／保存显示对应阶段。等待中不能重复提交。
- [ ] 临时中断下载／使用无效签名后原插件版本、数据和启停状态保留；确认框可以重试，过期候选可以刷新目录后重新选择。
- [ ] 停用插件更新后仍停用；启用插件安装／更新完成可直接打开，并正确切换独立插件工作区。卸载确认明确保留配置与历史。
- [ ] 版本详情显示发布说明、日期与本机／可安装版本；关闭后焦点回到入口。安装成功后若列表刷新失败，只重载列表，不重复安装。

- [ ] 系统设置、工作空间、目录与工具分组清楚；数据与诊断、版本与更新可以直接打开，页头和当前选中页面一致。

- [ ] 网页／备忘录筛选、选中和展开列表后切到其他页，再返回／前进，筛选、列表与主内容滚动位置恢复；没有自动保存或配置变化。
- [ ] 有未保存配置时切页，保存栏持续提示；撤销、重做、重置和关闭确认仍作用于同一份草稿。无效 JSON 不允许原生跳页或开始更新。
- [ ] 调整设置窗口宽度，侧栏与窄屏页面选择器切换正常，当前页及草稿不丢失；最小 640 × 360 窗口中标题、菜单、选择器和保存按钮均可操作。
- [ ] 从主体直接打开插件市场，独立插件栏、面板及设置窗口的原生跟随、关闭和焦点返回正常；不丢失主体草稿。
- [ ] 本次运行中首次打开设置，不点击正文直接使用 ⌘K 查找并输入关键词；新建插件栏不抢走键盘。关闭后重新打开设置，再重复一次；插件面板仍只在明确打开时接收焦点。
- [ ] 切换实际配置／数据位置后，原来源的筛选、选中或临时预览不出现在新来源；重开设置后页面展示状态重置，草稿恢复仍按原来源处理。

## 第六轮：目录与备忘录工作区

- [ ] 网页目录与备忘录宽窗口中并排显示列表和详情；缩窄后只显示当前面板，“列表”返回恢复原条目焦点及滚动位置。切到其他设置页再回来也能恢复。
- [ ] 宽窗口中分别聚焦搜索框、编辑字段后缩小窗口，当前输入控件仍可见；640 × 360 窗口内可滚动到全部字段和保存栏。
- [ ] 带筛选条件新建节点／备忘后，筛选清空，新条目在树中可见，标题自动获得焦点并选中文字；节点菜单中新增子级／同级也符合此行为。
- [ ] 点击“多选”后无需修饰键即可选择多个节点；详情只显示批量摘要。选择父节点及其子节点时，删除数量按独立分支及实际子节点计算，不重复处理。
- [ ] 使用临时节点验证批量移动到根目录、其他目录，顺序和子层级保留；目标列表排除所选分支本身及其后代。取消不改动，确认只形成一条草稿撤销，保存前不落地。
- [ ] 删除确认显示实际节点名称和子节点数量；取消、Escape 均不删除，确认后的撤销／重做恢复正确。确认期间底层目录变化会拒绝过期操作。
- [ ] 图标与高级属性、备忘说明与标签可展开编辑；标题、内容、标签和分类路径输入正常，普通左右键仍移动光标。分类修改及拖拽不丢失后代。
- [ ] 从目录操作导入临时文件，先核对差异再应用草稿；备忘录的恢复内置需二次确认，取消保留自定义库，确认后可以撤销。
- [ ] 深浅主题下菜单、空结果恢复、详情和批量摘要均清晰；浏览器预览只能筛选、选择及临时拖拽，新增、导入、移动与删除不可写入。

## 第七轮：配置审阅与数据管理

- [ ] 在不同设置页修改临时选项，“查看修改”按页面展示原值与新值；目录／备忘录变更显示数量及摘要。返回设置页继续编辑、关闭审阅后的焦点都正确。
- [ ] 审阅不自动保存，保存失败保留草稿和错误，重试只提交一次；保存期间无法重复提交、关闭或跳页。原有直接保存仍可用。
- [ ] 撤销到已保存内容、或将字段改回原值后重开设置，不再恢复已取消的旧草稿；其他来源及冲突源草稿仍保留。
- [ ] 配置文件与数据目录显示当前实际位置；选择临时目标后显示“待保存”及切换影响。“打开当前”仍打开生效位置，取消／恢复默认不保存无关修改。
- [ ] 历史版本先显示差异，网页目录与剪贴板记录不被误报为清空。取消不恢复；确认后配置确实恢复，原配置已备份，位置差异及重启提示准确。
- [ ] 历史读取失败能重试，取消后迟到结果不会重开弹窗。确认前修改底层草稿会要求重读；历史已提交但重读失败后能显式重新加载，并保留源草稿。
- [ ] 临时配置导入能核对合并／替换差异，应用只进入草稿且可撤销；导出范围正确，并明确不包含未保存修改。
- [ ] 诊断区的立即生效操作、单次采样、清理取消／确认及失败重试可用；不改动目录、备忘录或剪贴板数据。
- [ ] 深浅主题、窄窗口和 640 × 360 最小窗口中，存储目标、差异、错误与弹窗操作均可滚动访问。普通预览和示例历史无法执行任何原生写操作。

- [ ] 选中结果后滚动到目标并聚焦；菜单栏等折叠设置能自动展开。只读或禁用控件聚焦所在行，标示不影响继续输入、编辑及撤销。
- [ ] 查找清理、导入、检查更新、通知测试和授权入口只定位，不自动执行、写文件、访问网络或请求权限；原有确认仍需另行操作。仅用临时数据测试后续动作。

## 第九轮：主体导航与布局收尾

### 任务 1：导航连续性

- [ ] 筛选侧栏后缩窄至页面选择器，再恢复宽窗口，筛选词仍在；清除、Escape 和“显示全部页面”均可恢复全部入口。
- [ ] 较矮窗口中滚动侧栏，宽窄切换后回到原浏览位置；实际切换页面时当前项仍能进入可视范围。
- [ ] 聚焦侧栏查找框／页面按钮后宽窄切换，焦点进入新导航；正在正文输入时调整宽度不抢焦点。切换前后的页面与草稿一致。
- [ ] 保留侧栏筛选词，在窄窗口选择筛选范围外的页面，再放宽并聚焦导航：当前页不在筛选结果时回到查找框，筛选词与页面都保留，清除筛选后可以看到当前项。

### 任务 2：设置页信息层级

- [ ] 剪贴板的采集与隐私、历史保留、存储位置分组清楚；临时修改一个限额后切页，值与草稿仍在，撤销能恢复。旧排除列表的清空仍需明确点击并保存。
- [ ] 工具按网络、转换、本机、历史分类；所有已有开关都可找到，切换只进入草稿。历史清理仍先确认，取消／Escape 不删除任何记录。
- [ ] 深浅主题与 640 × 360 窗口中分组、输入框、存储路径和操作均可滚动访问；从设置搜索仍能准确定位到对应控件。

### 任务 3：保存与状态反馈

- [ ] 有草稿时执行测试通知、撤销或其他临时操作，保存栏仍明确显示“有未保存修改”，操作结果另行展示。不要把系统设置部分失败当作配置未写入。
- [ ] 修改临时选项后按 ⌘S，只保存一次；保存中连续按、长按及点击均不重复写入。保存成功后状态更新，干净状态下 ⌘S 不重复保存。
- [ ] JSON、搜索、修改审阅或确认弹窗打开时 ⌘S 不绕过当前流程；快捷键录入时可正常录入 ⌘S。中文输入组合不触发保存。
- [ ] 用可恢复的失败场景检查错误持续可见且草稿保留，重试后成功。深浅主题、长错误和 640 × 360 窗口中保存按钮与正文仍可访问。

### 任务 4：插件工作区衔接

- [ ] 从设置和插件栏打开市场／已安装插件，读取时有准备中提示；临时连接失败后可重新连接，恢复后不自动安装、启用或卸载插件，主体草稿仍在。
