# FlowHub 用户体验改进清单

## 1. 唤出稳定性与故障定位（进行中）

已有：按鼠标所在 NSScreen 定位、全屏辅助 Panel、Command+K 返回搜索框。

- [x] 保存结构化唤出诊断：屏幕布局、目标屏幕、窗口位置、原生可见与焦点状态、主线程排队耗时。
- [x] 日志遵守已有采样开关，后台写盘，不记录搜索词。
- [ ] 按 [唤出验收步骤](../launcher-verification.md) 验证双屏、不同缩放、全屏应用、切换 Space 与显示器拔插。
- [ ] 根据失败样本修复并重测；不能用几何单元测试代替真实全屏验收。

## 2. 搜索与长列表性能（已开始基线回归）

已有：快来源先显示、过期结果丢弃、分页并发保护、3000 行 DOM 窗口；设置页有滚动、输入和草稿采样。

- [x] 复跑现有合成前端压测，记录 [2026-09-08 基线](../search-stress-2026-09-08.md)，确认 3000 条分页与快来源先显示。
- [ ] 分开测量防抖、各来源查询、首批结果、渲染和下一帧等待；不记录查询内容。
- [ ] 压测连续翻页及全部／剪贴板／应用来回切换，记录 p50、p95、最大耗时、DOM 数量及内存趋势。
- [ ] 针对测得瓶颈优化；补充必要的防回退测试。
- [ ] 设置页长目录、备忘树与配置修改在真实 WebKit 复测。

验收：给出数据量、设备、版本、采样方法及前后结果，明确 JS 耗时与实际呈现延迟的区别。

## 3. 数据恢复与误操作保护

已有：自动保存本地草稿、启动时恢复草稿、删除确认、重置未保存配置。它们不能替代已保存配置的历史备份。

- [ ] 配置成功保存前生成有数量上限的历史备份，写入失败不破坏原配置。
- [ ] 提供备份列表、恢复预览和恢复操作；恢复前再次备份当前配置。
- [ ] 网页／备忘删除支持撤销，覆盖父目录及其子节点。

验收：损坏配置、保存失败、重启后恢复、父子节点撤销均可验证，测试只使用临时数据。

## 4. 剪贴板高频操作

- [ ] 核对现有复制、粘贴与清理规则后增加收藏／置顶。
- [ ] 支持纯文本粘贴，并明确快捷键与可用条件。
- [ ] 支持编辑文本副本，保留原始记录；收藏内容不被普通过期清理误删。

## 5. 统一结果操作与快捷键

已有：Command+K 返回搜索、结果键盘选择，以及部分工具的复制／刷新操作。

- [ ] 统一结果操作入口、Tab／F6 焦点顺序与 Escape 返回规则。
- [ ] 增加与实际绑定一致的快捷键说明；不显示未实现或当前不可用的操作。
- [ ] 验证输入法组合输入、长列表和工具操作之间的焦点切换。

## 6. 网页与备忘批量管理

已有：网页层级目录、可调整左右宽度；备忘合并同名祖先、类别折叠和搜索展开。

- [ ] 增加多选、批量移动分类及批量删除，复用撤销能力。
- [ ] 网页导入去重并预览冲突，备忘分类改名同步更新后代。
- [ ] 大数据量下保持选中项和滚动位置。

## 7. 命令历史与参数模板

已有：ping、curl、port、IP 等内置模块及独立开关；执行型网络工具需要明确触发。

- [ ] 为已执行命令提供有上限、可清空、可关闭的历史。
- [ ] 支持主机／端口／URL 参数模板、复制实际命令。
- [ ] 按工具校验参数；敏感内容不默认写入历史。

## 8. 配置迁移

- [ ] 核对已有配置存放位置与格式，提供整体／单模块导入导出。
- [ ] 导入校验格式版本，预览合并／替换差异，并复用备份恢复。

## 9. 剪贴板隐私控制

已有：剪贴板模块可关闭／暂停记录，不重复开发同一开关。

- [ ] 提供更容易找到的临时暂停入口及状态提示。
- [ ] 核对采集实现后增加按应用排除，明确来源识别失败时的行为。
- [ ] 验证排除应用的内容不会进入数据库、索引或缩略图目录。

## 执行原则

上述待办表示待核对或待实现，不意味着现有功能全部缺失。每次只推进有验证依据的改动，真实设备条件不足时保留验收待办，同时继续不依赖它的下一项。新改动默认留在工作区供查看；提交、推送及发布按用户后续要求执行。
