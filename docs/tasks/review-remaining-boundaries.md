## 未实现

- **按应用排除未实现**：macOS 没有可信的剪贴板写入方身份，`excludedApps` 非空时只能保守阻止全部采集。设置页会说明原因并提供「清空旧列表并保存」，搜索窗口显示「记录已阻止」；不提供添加排除项的入口，避免配置出一个静默停用采集的名单（见[剪贴板留存与操作](../architecture/clipboard/retention-and-actions.md)）。
- **非 macOS 采集未实现**：剪贴板隐私控制只在 macOS 生效。
- **未标记为秘密的内容仍可能被采集**：没有"标记后不再采集"的能力。
- **CSP 未进一步收紧**：仍允许内联样式与 HTTPS 图标。
- **旧库不自动升级**：不兼容的旧数据库直接拒绝，不提供迁移升级。
- **桌面到扩展无实时同步**：两边各自读配置，不推送变更。
