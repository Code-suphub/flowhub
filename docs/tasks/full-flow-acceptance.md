## 范围与基线

用户要求由一个 GPT-6.1 Terra 子代理独立验收，主代理修复发现的问题；覆盖页面布局、友好性、交互、实际操作体验与响应速度，按模块复测、提交和留档。

本轮使用独立工作树，不修改三个原主工作区的已有改动：

- 宿主：`codex/full-flow-qa-20261107`，起点 `700fbd4`。
- 插件：同名分支，起点 `096e053`；包含 2FA、Docker、机器管理、外设中心及其共享层的已完成重构。
- 公共组件：同名分支，起点 `9ab6c3d`。

普通安装版与上述源码分别核对。统一插件更新入口尚未装入普通宿主，资源监控另有已提交及未提交的宿主扩展；不能用当前验收宿主直接覆盖并丢失这些能力。相同版本不等于相同包指纹。

## 判定与证据

- 后端／行为测试、隔离 Chromium、隔离 WKWebView、普通安装版分别记账；模拟 API、`synthetic-dom` 或程序生成按键不证明用户硬件键盘、IME、全局焦点或多屏。
- 每项操作检查业务结果与必要的持久化／进程副作用，不能只用按钮点击返回、截图变化或命令退出码判成功。
- 布局检查宽窄窗口、短窗口、深浅主题、长名称和大数据；主界面错误可见，取消／失败保留必要上下文，键盘能进入并退出弹层。
- 性能记录数据规模、环境、驱动、输入到渲染延迟、长任务和布局耗时；算法微基准与页面／原生响应分开，不以自动化工具往返耗时代替应用响应。
- 普通安装版先只读核对；需要系统键鼠、安装或写操作时单独安排，防止与用户或其他会话抢桌面。用户配置、凭证、2FA 密钥、剪贴板及业务容器／进程／机器不作为破坏性测试夹具。
- 截图、原始日志、性能记录、私有测试脚本和用户数据留在 Git 外：`/Users/bilibili/.local/state/flowhub-full-flow-qa-20261107/`。Terra 证据放在 `terra/`，逐模块记录版本和驱动。
