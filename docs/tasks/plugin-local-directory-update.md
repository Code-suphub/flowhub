# 插件统一更新入口

## 操作流程

1. 首次安装选择插件的构建目录（例如 `build` 或 `dist`）。
2. 后续在同一目录重建，进入插件市场“已安装”，点击对应插件“更新”。界面只保留一个更新入口，市场安装自动从原来源更新。
3. 本地同版本重建与普通升级直接更新，降级或新增权限需要确认；市场更新沿用安装确认流程。更新保持原启停状态和业务数据。
4. 更换 worktree 或移动目录时，从该插件管理菜单选择“更换安装目录…”。不会因原目录不存在而自动弹出目录框。
