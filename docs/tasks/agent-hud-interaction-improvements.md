# FlowHub 布局与交互改进任务

参考：[Agent HUD](https://github.com/jazzenchen/agent-hud-open)。借鉴信息分层、明确的导航和常驻交互，沿用 FlowHub 现有主题、控件与键盘操作。

## 执行与审核

- 按编号顺序推进，每次只实现一项，由 sub-agent 实现，主代理审核代码及验证结果。
- 审核发现问题时修复并重审；通过后单独提交本项，展示结果并等待用户审核。
- 用户确认本项后才开始下一项。提交仅限本次改动，保留工作区已有修改；不推送、发布或安装。
- 提交前执行仓库根及 `app/` 的 `npm test`、`git diff --check`，并按本项补充必要行为验证。
- 页面检查覆盖真实点击、键盘、深浅主题和窄窗口。浏览器模拟不能替代原生焦点、多屏、Space 和遮挡验收，未验证项明确保留。
- 不改插件权限、只读预览边界或搜索输入性能约束；性能优化必须有测量依据。
