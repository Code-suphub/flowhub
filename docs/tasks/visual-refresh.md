# FlowHub 视觉优化任务

参考：<https://github.com/KKKKhazix/AIHOT>、<https://aihot.news/>。

## 执行方式

- 按下述顺序逐项实现，每次只完成一项。
- 每项完成后构建、验证并启动预览，等待用户确认效果；确认后再推进下一项。
- 实现优先由 `gpt-6-luna` 子代理负责，主代理检查变更、验证和展示效果。
- 保留工作区已有改动，不提交、发布或安装新版本，除非用户另行要求。
- 借鉴配色、层级和组件一致性，保留 FlowHub 的紧凑布局、键盘操作及原生能力。
- 使用现有 React 公共组件与 `--fh-*` 主题变量，保留深浅主题、只读预览和插件隔离。

## 1. 统一主题与公共控件

状态：用户已验收，已提交 `bd878f8`（`style: unify FlowHub theme and control states`）。

- 浅色采用温和中性背景、白色内容面；深色采用有明确层次的炭灰背景与表面。
- 使用低饱和蓝色强调色，集中于主要操作、选中态和焦点；错误、警告和成功保持独立语义。首次青绿色方案按用户反馈调整。
- 补齐公共字号、圆角、边框、阴影与交互变量；统一按钮、输入、选择器、帮助提示、弹窗等细节。
- 检查默认、悬浮、选中、聚焦、禁用状态，避免深色未选中导航也呈现明显按钮底块。
- 本项不改页面结构、不增加动效依赖、不调整业务行为。
- 验收：构建通过；公共控件与主题相关现有检查通过；设置、搜索、市场在深浅主题可读，窄屏无新增溢出。

## 2. 优化搜索浮窗

状态：用户已验收，已提交 `dea6a19`（`style: refine launcher layout and filter states`）。

- 收紧顶栏与输入框前的辅助区域，让搜索输入成为视觉中心。
- 搜索范围采用统一分段控件，保留现有快捷键和焦点行为。
- 统一常用入口图标、结果标题与元信息层级；根据当前场景精简快捷键提示。
- 验收：输入、范围切换、方向键、回车、上下文菜单可用；不引入输入期间同步扫描或无条件布局测量。

## 3. 优化设置导航与表单

状态：用户已验收，已完成，准备提交。

- 侧栏使用统一线性图标、常规字重和轻量选中态，保留现有模块分组。
- 调整设置表单宽度、行间距和标签到控件的距离；避免为少量内容制造过大的空白区域。
- 统一顶部工具、子分类与底部保存区层级；不更改保存、草稿、撤销和关闭语义。
- 验收：导航、下拉、帮助、弹窗、保存状态可用；深浅主题和窄屏可读。

## 4. 打磨网页目录与备忘录

状态：用户已授权开始；任务 3 提交后实施。

- 保留左树右详情；统一树行、缩进、图标、选中态、详情字段分组。
- 合并或弱化工具栏次要操作，改善未选择、无结果等状态。
- 验收：树展开折叠、选择、搜索、拖动及只读预览语义保持正确。

## 5. 打磨插件市场与相关页面

状态：待开始，依赖任务 4 用户验收。

- 统一插件图标、名称、描述、版本与来源层级，减少列表中技术路径的视觉干扰。
- 改善发现、已安装、来源和空状态的布局；与插件详情、状态页保持一致。
- 验收：标签页、过滤与相关操作保持可用；浏览器缺少原生数据时明确标注验证范围。

## 6. 整体复核

- 执行项目规定的最终检查；未经用户确认不发布或替换已安装应用。
