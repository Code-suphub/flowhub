# FlowHub 视觉优化任务

参考：<https://github.com/KKKKhazix/AIHOT>、<https://aihot.news/>。

## 执行方式

- 按下述顺序逐项实现，每次只完成一项。
- 每项完成后构建、验证并启动预览，等待用户确认效果；确认后再推进下一项。
- 实现优先由 `gpt-6-luna` 子代理负责，主代理检查变更、验证和展示效果。
- 保留工作区已有改动，不提交、发布或安装新版本，除非用户另行要求。
- 借鉴配色、层级和组件一致性，保留 FlowHub 的紧凑布局、键盘操作及原生能力。
- 使用现有 React 公共组件与 `--fh-*` 主题变量，保留深浅主题、只读预览和插件隔离。

## 1. 统一主题与公共控件

状态：用户已验收，已提交 `bd878f8`（`style: unify FlowHub theme and control states`）。

- 浅色采用温和中性背景、白色内容面；深色采用有明确层次的炭灰背景与表面。
- 使用低饱和蓝色强调色，集中于主要操作、选中态和焦点；错误、警告和成功保持独立语义。首次青绿色方案按用户反馈调整。
- 补齐公共字号、圆角、边框、阴影与交互变量；统一按钮、输入、选择器、帮助提示、弹窗等细节。
- 检查默认、悬浮、选中、聚焦、禁用状态，避免深色未选中导航也呈现明显按钮底块。
- 本项不改页面结构、不增加动效依赖、不调整业务行为。
- 验收：构建通过；公共控件与主题相关现有检查通过；设置、搜索、市场在深浅主题可读，窄屏无新增溢出。
