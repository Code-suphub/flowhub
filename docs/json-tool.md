# JSON 格式化

在“全部”搜索中输入或粘贴完整 JSON 对象／数组，自动显示 2 空格缩进预览；回车或“复制格式化 JSON”复制完整内容，“复制压缩 JSON”移除字符串之外的空白。

设置 → 智能工具 → JSON 格式化，默认开启，关闭后不参与结果。延续智能工具范围规则，剪贴板和备忘范围不显示此工具。

纯本地处理，无网络请求。通过 JSON.parse 校验语法，但输出使用原始词法 token，不重新序列化解析结果，因此大整数、指数形式、负零、重复键及转义写法保持原样。只识别对象和数组，避免数字与计算器冲突。不完整／无效 JSON 不出结果。

输入上限 65536 个 UTF-16 代码单元，嵌套上限 64 层。预览最多 40 行／6000 字符，截断有提示，复制仍为完整内容。缓存最后一次输入的格式化结果，避免每次渲染重复解析。

验证：JSON 单元测试覆盖结构、精度、转义、重复键、无效／超限输入、HTML 转义和复制。浏览器生产 UI 验证粘贴后自动出现格式化内容及两个按钮，大整数保持原值。10 组前端测试通过。
