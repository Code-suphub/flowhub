FlowHub 0.1.7

- 新增 `port 9000` 端口与进程查询，展示启动时间、运行时长，支持确认后结束进程及复制 macOS / Linux 查询命令。
- 公网 IP 渐进返回，支持备用服务、取消过期请求和复制地址；端口查询合并重复刷新、批量读取进程信息。
- 改进设置页导航、图标与提示，减少隐藏页面扫描和重复渲染。
- 优化全部范围分页、长列表渲染及搜索结果分批显示。
- 更新包保存到磁盘，重启后可继续安装，错误提示更易查看。
- 改善双屏菜单栏条目筛选、分隔项间距、恢复排序，以及级联菜单高亮、圆角和延迟收起。

请选择与 Mac 芯片对应的 DMG：Apple Silicon 使用 aarch64，Intel 使用 x64。

当前仍采用本地开发证书签名，未完成 Apple 公证。菜单栏整理需要辅助功能权限；端口查询可能无法看到其他用户的进程。
