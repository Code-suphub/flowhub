# FlowHub v0.1.8

- 修复“全部”范围无法追加剪贴板、网页及备忘结果，长列表可以到达真正末页。
- 优化剪贴板预览的首次状态符号渲染和重复同步布局，补充分阶段搜索诊断。
- 新增 JSON 格式化、压缩复制，保留大整数及原始键顺序。
- 新增 URL 自动解析、参数单独复制及 urlencode / urldecode 组件编解码。
- 改进网页与备忘编辑布局、分类折叠，支持 Command+K 返回搜索。
- 优化鼠标所在屏幕的浮窗定位，并增加本地唤出诊断。

原生采样验证了本机真实长列表分页与已复现慢帧场景。双屏全屏唤出在不同机器上的表现、其他字形首次渲染和完整外部升级链路仍需持续验证。
