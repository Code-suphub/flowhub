# Arc 标签页复用（2026-09-08）

配置：通用设置 → 搜索入口 → 网页打开方式 → 优先复用已有标签页（Arc）。持久化字段 core.reuseBrowserTabs，默认关闭；本机已按用户要求开启。

## 行为

- 默认浏览器为 Arc 且开启开关时，查询普通窗口的 Spaces，匹配完整的规范化 HTTP(S) URL；保留路径大小写、查询参数和片段，不使用同域名匹配。
- 找到后 select 原标签页并激活 Arc，不重设 URL、不主动刷新。
- 未找到时在 Arc 普通窗口当前 Space 新建标签页，短暂等待 Arc 异步发布后选中。避免依赖创建命令的不可靠返回对象。
- Arc 未运行、无普通窗口、权限拒绝、错误或超时，回退到原有系统默认打开逻辑。关闭开关或其他浏览器也沿用原逻辑。
- 不检索隐私窗口；不会启动 Arc 来扫描。批量读取各 Space 的 URL，避免对数百个标签逐个跨进程请求。
- 静态 AppleScript + 独立 argv 传递 URL，不拼接为脚本。子进程 8 秒硬超时，执行在后台；网页打开请求串行化，避免并发新建重复标签。
- 提供 --open-web URL 本地调用入口，使用与搜索结果 activate_target 相同的 web_open::open 路径。该入口仅在已运行实例中处理，不包含历史使用记录写入和隐藏悬浮窗的 UI 步骤。
- 诊断 web_open 只包含结果和耗时，不记录 URL 或页面内容。

打包增加 Apple Events 用途说明和自动化 entitlement。首次可能出现 macOS 控制 Arc 的授权提示，拒绝后回退到普通打开。

## 实际安装版验证

版本 0.1.8-local.20260908154416。Arc 当时约 500 个普通标签页。使用本机 HTTP 测试页面，arcctl 核对标签页 ID、URL 和当前选中项；调用安装版 FlowHub 的真实网页打开函数。

| 场景 | 结果 | 耗时 |
| --- | --- | --- |
| 已有链接，先切到其他标签再打开 | reused，原 ID，数量 1→1，切回成功 | 260ms |
| 路径相同、查询参数不同 | opened，数量 0→1，选中新页面 | 1564ms |
| 再次打开带参数链接 | reused，原 ID，数量 1→1，切回成功 | 566ms |
| 关闭开关 | disabled，调用原系统打开逻辑，没有执行复用 | 68ms |

最后恢复开启，清理本次普通测试标签页，并切回测试前的原标签。关闭开关用例只验证回退路径，未将系统接受打开请求等同于新建普通标签成功。未实测隐私窗口、其他默认浏览器和权限拒绝场景。

47 项 Rust 测试、13 组 UI 测试通过。URL 测试覆盖规范化、大小写、查询/片段保留、字面脚本字符与非法协议拒绝。
