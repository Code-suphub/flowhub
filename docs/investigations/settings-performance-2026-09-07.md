# FlowHub 本机性能采样（2026-09-07）

## 方法与范围

macOS 已安装的 Tauri / WebKit 设置窗口，980 × 720。现有性能采样开关已开启。
对菜单栏长页执行多次上下滚动，对“显示版本号”执行 12 次开关切换，最终恢复原值；未保存测试配置。
两轮分别使用 0.1.6-local.20260907071905 和 0.1.6-local.20260907072258。

滚动使用 scroll 事件及其后 150ms 内的 requestAnimationFrame 帧间隔；等效帧率为 1000 / 平均间隔，不是显示器实际呈现帧率，不包括首次输入到呈现延迟。
输入耗时包裹设置页 input 处理函数，只测同步 JS，不含后续布局、绘制和系统配置应用。
草稿计时包裹序列化、localStorage.setItem 和状态更新；不代表物理磁盘 fsync 时间，也不包括 120ms 防抖等待。
性能时钟精度约 1ms，样本量较小，结果用于发现明显额外开销，不能证明所有配置和长时间运行都流畅。

## 结果

| 指标 | 第一轮 | 局部刷新优化后 |
|---|---:|---:|
| 滚动样本数 | 84 | 78 |
| 等效帧率 | 58.9 fps | 59.2 fps |
| 帧间隔 p50 / p95 | 17 / 18ms | 17 / 17ms |
| 最大帧间隔 | 36ms | 41ms |
| >33.3ms 帧数 | 1 | 1 |
| 配置输入样本 | 12 | 12 |
| 输入 p50 / p95 / max | 3 / 20 / 20ms | 1 / 2 / 2ms |
| 草稿样本 | 6 | 6 |
| 草稿 p50 / p95 / max | 1 / 7 / 7ms | 1 / 7 / 7ms |

确定的优化：非主开关不再调用 renderSettingsFields 重建菜单栏图标列表及其他隐藏设置。主开关仍刷新依赖控件的禁用状态。
滚动改善不显著，不能归因于本轮改动；两轮均存在一次明显慢帧。后续应采集更长的真实滚动和图形合成跟踪。

## 其他检查

此前对 2262 条剪切板记录的只读 SQL 查询测试：空查询中位 0.04ms，文本查询中位 2.21ms，无匹配中位 2.46ms；这不含 IPC / 图片加载 / 渲染。
移除非空搜索重复查询常用/最近记录，保留空查询和使用记录变更时刷新。
全部搜索原来固定截断且无滚动加载分支，现增加稳定顺序分页、缓存优先、后端补页、并发保护和末页提示。
回归测试覆盖 52 条剪切板模拟记录在全部模式下的稳定前缀、唯一性和后台补页；浏览器前端验证“全部”从 24 增长至 48 条。

仍需关注：搜索 180ms 防抖是有意等待，不能与数据库耗时混为一谈；全来源搜索等待各来源完成，慢来源可能推迟结果；长列表当前仍全量生成 DOM，大量连续翻页尚未做长时间压测。未声称这些路径已全部优化。

## 复现

开启 设置 → 通用设置 → 数据与诊断 → 启用采样，点击重置界面测量，进行操作，再点击读取界面测量。
统计仅保留当前窗口最近 2000 个各类数值样本，不采集输入内容；关闭采样后停止记录。

回归命令：

```sh
node app/scripts/all-pagination.test.cjs
node app/scripts/settings-performance.test.cjs
```
