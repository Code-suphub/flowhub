# 菜单级联外观修正

原级联面板使用无边框 NSButton，没有显式菜单文字颜色；鼠标进入只打开子菜单，没有绘制悬停或父级选中态。毛玻璃仅依赖 layer.cornerRadius 裁剪，缺少 NSVisualEffectView.maskImage。

现增加 Active/Emphasized Selection 毛玻璃作为行高亮；启用项用 labelColor，高亮项用 selectedMenuItemTextColor，禁用项用 disabledControlTextColor。进入子菜单保留祖先高亮，切换同层项目清除旧选择；从深层入口打开时初始化祖先高亮。圆角 alpha mask 同时应用于菜单背景与高亮背景，原有图层裁剪保留以约束子视图。

37 项 Rust 测试及 6 组前端回归通过。后台 FlowHub 和 SystemUIServer 的自动化访问超时，因此本次不能声称已完成真实菜单截图验收；仍需核对浅色/深色外观、悬停切换及圆角透明区域。

菜单栏整理子菜单宽度改为按实际 13 pt 字体测量最长选项，再加 48 pt 的文字缩进、箭头和边距；最小宽度由 180 pt 降至 136 pt。只调整这一层，图标开关列表仍保留其原有宽度。

鼠标经过非子菜单行时，延迟 500 ms 再切换/关闭后代菜单。延迟操作使用版本号取消；执行前检查鼠标是否进入可见后代窗口，进入则保持展开。重新经过子菜单入口和关闭整个会话会使旧延迟失效。使用异步计时，不为每次悬停创建原生线程；菜单外点击和 Escape 仍立即关闭。

## 离开后不再收起的修复

前一版仅在进入非子菜单行时安排延迟，直接移出全部面板不会触发；进入子菜单取消后也没有重新计时入口。现仅在菜单会话可见期间，每 50 ms 检查鼠标是否位于可见菜单或锚点，连续在外 500 ms 后关闭；重新进入则清空计时。关闭会话使旧检查失效；主线程确认完成后才安排下一次检查，避免积压。图标自动移动期间暂停检测并清空计时，避免合成拖动误关菜单。

新增边界测试：499 ms 不关、返回取消、再次离开完整等待 500 ms。39 项 Rust 测试和 6 组前端回归通过；真实鼠标跨菜单视觉体验尚未自动化复现。
