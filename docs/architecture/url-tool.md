# URL 解析与编解码

设置 → 智能工具 → URL 解析与编解码，默认开启。遵守智能工具范围规则，剪贴板和备忘范围不展示。

- 粘贴完整 HTTP/HTTPS URL 自动显示协议、主机、端口、原始路径、解码路径、原始查询、参数及片段。
- 参数保持原顺序和重复项。每项可单独复制，回车复制解析详情。
- `urlencode 中文 +` 按 URI 组件规则编码为 `%E4%B8%AD%E6%96%87%20%2B`。
- `urldecode %E4%B8%AD` 解码为 `中`；非法百分号或 UTF-8 编码明确提示失败，不猜测或修复。
- 组件解码保留字面 `+`。URL 查询参数按 URLSearchParams 表单规则把 `+` 解释为空格，原始查询同时保留。

全程本地处理，不发起请求或自动打开链接。输入上限 65536 个 UTF-16 代码单元；表格最多预览 20 项、每值 500 字符；编解码最多预览 4000 字符。复制为完整内容。结果只缓存在本窗口最后一个输入中。
