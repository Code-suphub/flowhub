# 设置页：网页目录与备忘编辑器

网页目录和备忘录由 `app/src/settings/Collections.tsx` 渲染，共用 `collection-ui.tsx` 的字段、详情页头、空状态和列表返回逻辑。宽屏并排显示目录树与编辑器，正文宽度不超过 660 像素时在列表和详情之间切换。网页目录本体存在当前存储目录的 `weborg.db`（`web_catalog_nodes`），配置文件里的 `plugins.web.settings.items` 保持为空并标记 `catalogStorage: "sqlite"`。

## 目录树

- “新建节点”创建根节点；节点操作菜单提供子节点、同级节点、移动和删除。新增时清除筛选、展开祖先，并聚焦选中新条目的标题。详情优先展示标题、链接和备注，图标、强调色和内部 ID 收在高级属性中。
- 多选：可点击“多选”后逐项选择，或按住 ⌘/Ctrl/Shift 点击。多选详情只展示批量摘要及独立分支列表，不再编辑第一项的属性；窄屏通过“管理所选 N 项”进入摘要。批量删除与移动各记成**一条**撤销。祖先也在选中集合里时只按最外层处理，避免重复；移动目标排除所选分支及其后代，可移动到根目录。
- 移动和删除确认记录打开时的分支、数量及目录快照；删除显示名称与实际后代数量。取消不改草稿，确认时目录已变化则提示关闭后重选，不对过期对象继续操作。
- 拖拽与批量操作都只改编辑器里的草稿，点「保存配置」才走正常保存管线（journal、历史备份、系统集成）。
- 长目录重绘（展开／折叠、增删、导入）时保持视口：先记住视口顶部那一行及其相对位置，重绘后按同一位置还原，锚点行被删掉时退回原滚动偏移，目录清空时归零；行内焦点按节点 ID 还原。选择由新增、导入、批量移动、撤销等动作改到视口外时会把该行带进视口，用户自己滚动时不会被拉回。筛选条件变化时回到顶部。

## 网页导入

目录操作菜单中的“导入目录”从 JSON 文件读入节点，支持裸数组、`{items:[…]}`、完整配置和导出信封四种形态（上限 8 MiB），只解析不落地，写入仍走正常保存管线。确认框按现有目录算出“新增／覆盖／跳过”，切换重复 ID 策略会重新展示对应差异：

- id 相同视为同一节点；没有子节点且网址相同的页面也算重复；文件内自身重复单独标注。
- “跳过”保留已有节点；“覆盖属性并合并子节点”替换同 id 节点的字段，并把导入的子节点按同一规则挂到已有节点上（不会整棵替换 `children`）。
- 被跳过的节点不再单独导入其子节点，避免半个分支混进目录。
- 整次导入记成一条撤销。

## 备忘

- 分类是路径式（`父 / 子`），同名祖先会合并成一个分类节点；分类可折叠，搜索时自动展开命中路径。
- 详情展示标题、分类路径和内容，说明与搜索标签可展开编辑。字段标签与输入控件关联；新增后清除筛选并聚焦标题。
- 离开分类输入框时级联更新后代备忘的分类前缀；分类和条目拖拽继续使用原有移动模型。
- 恢复内置命令库收在备忘录操作菜单，删除收在当前备忘的操作菜单。确认框显示当前数量或备忘名称，记录操作对象及快照；底层内容已变化则拒绝过期操作。恢复与删除都只改变草稿，可撤销。

## 配置历史与迁移

- 每次成功保存前，被替换的配置都会在配置目录的 `history/` 里留一份有上限（20 个）的备份；保存失败不会破坏原配置。设置页可以列出、预览差异并恢复某个版本，恢复会先把当前配置记入历史。
- 导出／导入支持全部、全局设置与单个插件三种范围；导出文件带格式版本与来源版本，导入会预览「替换」与「合并」两种差异后再应用。
- 导入的 `items` 不参与覆盖：网页目录存在数据库里，导入配置时保留本地目录，不会因为导入文件里 `items` 为空而清空目录。
