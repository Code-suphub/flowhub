# 设置页：网页目录与备忘编辑器

设置页左侧是网页目录树（`#structurePanel`），右侧是选中节点或备忘的编辑器；网页目录本体存在当前存储目录的 `weborg.db`（`web_catalog_nodes`），配置文件里的 `plugins.web.settings.items` 保持为空并标记 `catalogStorage: "sqlite"`。

## 目录树

- 层级编辑：新增一级目录／子节点／同级节点、拖动整行调整顺序与层级、上移下移置顶置底、删除分支（删除前确认，并提示会一起删掉的子节点数）。
- 多选：按住 ⌘/Ctrl 或 Shift 点击累加选中；工具栏显示选中数量、批量目标目录与「删除 N 项」。批量删除与批量移动都按操作前的整棵目录记成**一条**撤销，撤销时连选中项一起恢复。祖先也在选中集合里时只按最外层处理，避免重复；移动会拒绝目标为自身或其子目录。
- 拖拽与批量操作都只改编辑器里的草稿，点「保存配置」才走正常保存管线（journal、历史备份、系统集成）。
- 长目录重绘（展开／折叠、增删、导入）时保持视口：先记住视口顶部那一行及其相对位置，重绘后按同一位置还原，锚点行被删掉时退回原滚动偏移，目录清空时归零；行内焦点按节点 ID 还原。选择由新增、导入、批量移动、撤销等动作改到视口外时会把该行带进视口，用户自己滚动时不会被拉回。筛选条件变化时回到顶部。

## 网页导入

「导入目录」从 JSON 文件读入节点，支持裸数组、`{items:[…]}`、完整配置和导出信封四种形态（上限 8 MiB），只解析不落地，写入仍走正常保存管线。导入前按现有目录算出「新增／覆盖／跳过」并同时展示两种结果：

- id 相同视为同一节点；没有子节点且网址相同的页面也算重复；文件内自身重复单独标注。
- 「仅导入新增」跳过所有冲突；「覆盖同 ID」用导入内容替换同 id 节点的字段，并把导入的子节点按同一规则挂到已有节点上（不会整棵替换 `children`）。
- 被跳过的节点不再单独导入其子节点，避免半个分支混进目录。
- 整次导入记成一条撤销。

## 备忘

- 分类是路径式（`父 / 子`），同名祖先会合并成一个分类节点；分类可折叠，搜索时自动展开命中路径。
- 重命名分类会级联更新所有后代备忘的分类前缀，并提示同步了多少条。
- 恢复内置命令库会替换所有自定义备忘，属于破坏性操作，按钮单独放在「管理命令库」里。

## 配置历史与迁移

- 每次成功保存前，被替换的配置都会在配置目录的 `history/` 里留一份有上限（20 个）的备份；保存失败不会破坏原配置。设置页可以列出、预览差异并恢复某个版本，恢复会先把当前配置记入历史。
- 导出／导入支持全部、全局设置与单个插件三种范围；导出文件带格式版本与来源版本，导入会预览「替换」与「合并」两种差异后再应用。
- 导入的 `items` 不参与覆盖：网页目录存在数据库里，导入配置时保留本地目录，不会因为导入文件里 `items` 为空而清空目录。
