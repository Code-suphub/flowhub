# 设置搜索与精确定位

页头提供统一“搜索设置”入口。设置窗口中使用平台主修饰键加 K（macOS 为 ⌘K，其他浏览器平台为 Ctrl+K）打开；再次按下会聚焦并选中当前查询。侧栏继续提供页面筛选，窄窗口仍保留原有页面选择器。

`settings-search.ts` 维护宿主页面、设置项与操作入口的静态索引，支持中文常用说法、英文关键词、多个词组合及全半角归一化。精确标题优先；空查询展示常用项与页面，每次最多返回 60 项。索引不读取用户目录、备忘录、剪贴板、文件系统或在线市场，输入过程中没有原生调用。

`CommandSearch` 复用当前安装的 Base UI Autocomplete，提供分组、活动项、键盘上下选择与回车激活。输入保持焦点，左右键仍用于光标移动；输入法组合期间的回车不触发选择。Escape 关闭弹窗并恢复原焦点。其他弹窗打开、配置加载或保存时不再叠加搜索；快捷键录入已经消费的按键不会触发全局搜索。

## 定位行为

选择结果只执行导航和定位。清理、导入、通知测试、检查更新及授权入口都需要用户在定位后另行操作，原有确认与权限边界不变。插件市场结果沿用独立插件工作区入口。

控件通过 `data-setting-label` 与索引目标关联；行内控件使用 `data-setting-control` 区分帮助按钮。`useSettingLocation` 仅在明确的定位请求后展开目标所在折叠区、滚动并聚焦控件，短暂标示目标。只读或禁用控件定位到所在行，普通字段输入不触发重新定位或布局测量。

定位保留导航历史和当前草稿，不自动保存。新的指针或键盘操作会取消排队中的焦点转移；数据来源变化或页面离开时清除旧请求和标示。公共 Dialog 关闭时也会尊重用户已经选择的新焦点，防止延迟回焦覆盖连续输入。

`settings-search.test.cjs` 校验索引唯一性、别名和排序、全部目标与实际页面的对应关系、中文组合回车、快捷键录入、只读定位、延迟焦点取消，以及操作入口不执行业务动作。浏览器验证补充真实滚动、键盘、深浅主题、窄窗口与输入期间的性能记录；原生辅助功能和独立工作区焦点仍需实机验收。
