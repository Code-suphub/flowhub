# 配置审阅与数据管理

全局保存栏在存在草稿时提供“查看修改”。审阅按设置页面分组，展示原值、新值以及新增／移除／修改；可以返回对应页面继续编辑，也可以保存全部修改。保存失败保留审阅和草稿，保存期间禁止重复提交与跳页。审阅是可选入口，原有直接保存、JSON 编辑和关闭确认继续有效。

`config-changes.ts` 负责比较和展示摘要，`ConfigChanges.tsx` 复用于草稿、导入和历史预览。比较只在相应界面打开时运行，不在普通字段输入中扫描目录或生成差异。数组作为单项变更，网页／备忘录额外显示节点数量及新增、移除、修改摘要；每次最多渲染 100 项，更多内容按需展开。凭据、密钥等字段只显示设置状态；完整 JSON 仍由原有显式入口查看。

编辑或撤销回到已保存内容时，清除当前来源的旧草稿缓存，防止下次打开重新恢复已经撤销的修改。其他来源的草稿和保存冲突的恢复边界不变。有效编辑、撤销和重做清除过期错误状态。

## 存储位置

`DataPanel.tsx` 集中提供配置文件及数据库／剪贴板位置；剪贴板页继续复用同一位置控件。每个控件分别展示当前生效路径和待保存目标。选择与恢复默认只改草稿，“打开当前”始终打开实际生效位置。原生选择器返回时若当前草稿已变化，拒绝覆盖较新的编辑。

配置文件保存后切换，原文件保留；数据库目标为空时接收当前数据，目标已有数据库时加载目标数据，源网页草稿不合并。位置待保存时直接显示这一影响说明。

## 历史、导入和诊断

历史列表先读取备份，再显示与打开时草稿的差异；恢复入口也需要完成这一步。读取失败可以重试，取消后到达的旧结果不会重开弹窗。确认期间草稿变化时要求重新读取，避免放弃未核对的新编辑。

配置历史只回退配置文件，不重写当前 SQLite 中的网页目录和剪贴板记录；因此历史比较保留当前网页目录。恢复立即写入配置，当前已保存配置先备份，未保存草稿会被放弃。系统集成与数据目录差异可能需要重启，配置文件目标差异会在后续保存时切换。历史已提交但重读失败时，保留源草稿，提供显式重载当前配置的恢复入口。

导出使用当前已保存配置，存在草稿时明确提示。导入基于选择文件时的草稿生成合并／替换差异，应用前再次校验草稿；只形成一条可撤销编辑，不自动保存。网页目录继续使用当前数据库。

诊断区标明“立即生效”，与配置草稿区分。性能采样、手动采样和清理继续使用现有原生接口；清理需显式确认，失败保留弹窗和重试能力。

普通浏览器预览不能写入。显式 `preview=demo` 提供内存中的示例历史用于布局与比较验证，不读取本机配置、数据库或历史文件。
