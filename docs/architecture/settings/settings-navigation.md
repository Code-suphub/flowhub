# 主体导航与页面布局

设置主体使用 `app/src/settings/navigation.ts` 的唯一页面表。系统设置包含通用、外观、数据与诊断、版本与更新；工作空间包含搜索、菜单栏、桌面组件；目录与工具包含网页目录、应用、剪贴板、备忘录、工具。数据与更新不再嵌在通用设置标签页中。页头只显示当前分组和页面标题，正文提供对应操作。

宽窗口显示可滚动侧栏，通过名称和用途关键词查找页面。输入法组合期间不处理回车，输入中的左右键保持光标行为；只有单一匹配时回车进入，Esc 清除查找。导航按钮的上下键、Home、End 只移动焦点，回车才切页。窄于 700 像素时用公共 Select 提供全部页面入口，不同时挂载第二套侧栏。调整宽度保留当前页面。

侧栏筛选与滚动位置保存在当前窗口的展示状态中，宽窄切换后恢复；数据来源变化时清除。仅在实际切页时将当前项滚入可视范围，重挂载不覆盖原浏览位置。导航控件因断点切换被卸载时，将焦点转交新导航；正文仍有焦点时不转移。侧栏空结果提供显式恢复全部入口。

窄窗口可以选择侧栏筛选范围外的页面；恢复宽窗口时仍保留页面与筛选词，导航焦点在找不到当前项时回到查找框，避免落入正文之外。

页头的统一[设置搜索](settings-search.md)覆盖具体控件与操作入口，支持 ⌘K / Ctrl+K。结果可以跨页展开折叠区域、滚动并聚焦目标；导航历史和草稿继续沿用当前窗口状态，定位不自动执行按钮或切换开关。

返回与前进使用当前窗口最多 40 条页面历史；重复选择当前页不入栈，后退后选择新页面丢弃前进分支。直接页面 URL 从目标页开始，没有未访问的默认页历史。旧原生 `switchModule`、菜单更新、添加网页入口继续有效，原生回调使用当前导航函数。无效 JSON 或保存中的状态会阻止切页；更新请求也不能绕过 JSON 检查。

主内容、侧栏各自滚动，页头与保存栏保持可见。网页和备忘录的筛选、选择、展开状态、临时只读预览及列表滚动位置保存在当前设置实例的内存中；主内容滚动按页面恢复。离开页面会卸载正文与其监听，返回时恢复展示状态，不保留隐藏的运行页面。字段输入不触发滚动恢复或布局测量。

展示状态不写配置、不触发保存。配置文件或数据目录的实际位置变化时更换展示状态容器并重新挂载页面，防止把旧来源的选择或预览带入新来源；关闭窗口后丢弃。配置草稿、撤销、重做、恢复及关闭确认继续由 `SettingsStore` 管理，切页不自动保存。保存栏在其他页面也持续显示未保存状态。

菜单栏筛选与临时示例显示状态、数据导出范围也使用同源展示记忆。`ViewDetails` 保留原生 details 语义，并将用户或搜索定位触发的展开状态写入当前窗口内存；网页和备忘高级区域按条目 ID 分别记忆。数据来源变化或新窗口清空这些状态，已移除的导出插件范围回到全部配置。确认框、错误、授权和进行中的请求不进入展示记忆。

保存栏的“查看修改”按页面展示草稿差异，并可返回对应设置页继续编辑；跳转后焦点进入正文，普通关闭审阅则返回原入口。差异仅在打开审阅时计算。导入和历史预览复用同一比较组件，具体提交与恢复边界见[配置审阅与数据管理](configuration-review.md)。

`SettingsFooter` 持续显示配置状态，操作结果和错误单独呈现，不用通知结果覆盖未保存提示。长错误可以聚焦并滚动阅读，保存栏限制高度以保留正文空间。平台主修饰键加 S 使用同一份草稿保存流程，干净配置、保存中、来源冲突、只读预览和其他弹窗不会触发保存；输入法组合、快捷键录入及已消费的按键继续交由当前控件处理。

网页目录和备忘录共用列表／详情结构。内容区域宽于 660 像素时并排显示；更窄时选择条目进入详情，通过“列表”返回，恢复列表滚动及原条目焦点。断点按正文容器宽度判断，切换主体侧栏不会挤压编辑表单；列表／详情状态和返回位置也保存在当前窗口内存中。宽窗口中聚焦列表或编辑器会记录当前面板，缩窄后保留正在操作的面板。详情的标题、路径、字段和高级属性遵循同一套组件与标签关联方式。

剪贴板按采集与隐私、历史保留、存储位置分组；工具按网络与连接、转换与解析、本机与进程、历史与模板分组。分组复用 `SettingsSection` 的 FieldSet／FieldLegend／FieldGroup，工具类别随正文可用宽度自动并排或纵向展示。所有原有配置控件和搜索目标保持可用，分类本身不改动配置；历史清理仍需明确确认。

从原生入口新增网页属于明确定位请求：清除旧筛选、选中新增项并展开父级，随后消费该请求。普通返回不会重复定位旧的外部请求，也不会覆盖用户后续选择。

侧栏和窄屏页面选择器都可直接打开插件市场；原生调用独立插件工作区，保留设置正文和草稿。浏览器继续使用原有只读工作区预览，关闭后焦点返回入口。主体导航不改动 Tauri 插件权限或启动器唤出与输入逻辑。

桌面组件页区分状态读取与明确操作。初始读取失败后提供原地重读，重读只查询状态；读取和操作中的重复请求被拦截。新原生事件优先于旧读取结果，模式修改失败保留原显示值。切页后旧请求不能回写或派发模拟模式事件，浏览器预览与缺少原生桥时不提供写入路径。

`settings.css` 管理页面控件，`glass.css` 提供既有材质及插件工作区样式，`layout.css` 管理主体布局；移除被替换的横向导航及通用标签栏样式。颜色沿用 `--fh-*` 语义变量。显式 `settings.html?preview=demo` 使用内存示例配置及示例位置，不请求本机配置或剪贴板存储接口。
