# 结果操作、焦点顺序与快捷键

搜索窗口里的每条结果都在同一个位置暴露「当前可用」的操作：内置结果由 `resultActions()` 生成 `result-actions` 操作栏，工具结果与剪贴板记录自带同类按钮（`data-tool-action` / `data-clipboard-action`），不再重复渲染。按钮和键盘都走同一条路径（`runResultAction` 或各自的工具动作），不存在只有鼠标能触发的操作。

## 操作栏

| 结果类型 | 动作 |
| --- | --- |
| 网页 | 打开、复制链接 |
| 网页「添加到配置」 | 打开、复制链接 |
| 应用 | 打开、复制路径 |
| 备忘 | 复制命令、粘贴 |
| 2FA | 复制验证码 |
| 计算／时间戳／JWT | 复制结果 |
| DNS／IP | 复制查询命令 |
| ping／curl／端口等工具 | 工具自带按钮（执行、复制命令、复制输出、刷新、结束进程…） |
| 剪贴板记录 | 置顶、纯文本粘贴、编辑副本（见[剪贴板留存与操作](../clipboard/retention-and-actions.md)） |

没有可用动作的结果（例如纯提示行）不渲染空操作栏。

## 焦点与 Escape

打开网页或应用时，原生主线程先隐藏启动器，再执行浏览器标签复用或应用启动；使用记录更新放在成功之后。等待期间暂停结果重绘和悬停选择，同一轮打开只提交一次。打开失败恢复原查询和选中项；用户已重新唤出或主动收起时，旧请求不能恢复、隐藏或覆盖新一轮窗口。

- 搜索框是默认焦点。普通结果的 `↑↓` 逐项移动；`Tab` 切换搜索范围（按住 `Tab` 再用方向键逐个切换）。仅在输入框值和当前查询都完全为空、焦点位于输入框且选中快捷入口时，无修饰键的 `←→` 在同排移动，到边界停留并更新记忆列；有文字、空格、待更新查询、操作按钮焦点或输入法组合输入时，左右键交给原控件。
- 空查询的全部、应用和网页范围同时显示「常用」「最近」两排紧凑入口，各自保留当前范围的数据；空组显示独立空态，不影响另一组。上下键跨排并保持选中列，鼠标选择更新记忆列；短排暂选末项，返回时恢复原列。空排跳过，最后一排向下进入首条普通结果，首条普通结果向上回到最后一排的记忆列；查询和范围变化重置记忆列。同一对象可在两个快捷入口组中各出现一次。
- `F6` 进入当前结果可用操作，再按 `F6` 向后、`⇧F6` 向前，走过最后一个按钮回到搜索框。普通结果的展开按钮之后仍可进入更多菜单；快捷入口没有操作按钮时回到搜索框。
- 焦点在操作栏里时 `Tab` 交给浏览器的默认顺序，不再切换范围；`Esc` 先回到搜索框并选中现有关键词，再按一次才隐藏窗口。
- `⌘K` 在任何时候都回到搜索框。
- 键盘方向导航后使用键盘选中高亮，静止鼠标在滚动或重绘后产生的事件不改变选择；鼠标坐标发生实际变化后恢复悬停选择。重新唤出会重建坐标基线，明确点击不受此规则限制。
- 输入法组合输入期间（`isComposing`／`keyCode 229`／`Process`，以及回车提交后 80ms 内）以上快捷键都不生效，按键交给输入法；编辑剪贴板副本时键盘只归编辑框，`Esc` 取消编辑，`⌘↩` 保存。

## 快捷键说明

### 录入与跨平台格式

设置录入、别名比较和搜索范围键触发共用 `app/ui/shared/shortcuts.js`；React 通过类型适配层使用同一实现，搜索页直接加载该脚本。

- Command 录入为后台支持的 `Command`，macOS 界面显示 `⌘`。后台注册兼容旧配置中的 `Meta`／`OS`，无需用户重新录入；不会把不认识的键静默替换成默认快捷键。
- `Meta`、`Command`、`Cmd`、`Super` 使用相同的修饰键语义；`CommandOrControl` 的四种名称按当前平台解析，macOS 对应 Command，其他平台对应 Control。冲突检测与触发采用相同规则。
- 优先读取 `KeyboardEvent.code`，避免 Option 的特殊字符、Shift 的标点变化和输入布局改变存储的按键。保留数字小键盘及小键盘 Enter 的独立身份。没有 code 时仅接受可识别的兼容键名。
- 输入法组合中、重复事件和单独修饰键不会录入。macOS 全局注册器尚未支持的 F21–F24、媒体键会在录入时提示；范围键和其他平台按各自能力处理，不能据此保证所有硬件层 Fn 行为。
- 无修饰键的 Escape 取消录入，无修饰键的 Delete／Backspace 清空允许清空的范围键；带修饰键时按普通组合键录入。

底部说明由 React `KeyboardHint` 按当前选中结果和运行环境动态生成，只列真的可用的操作：非剪贴板结果不显示剪贴板快捷键，图片记录不显示纯文本粘贴与编辑副本，浏览器只读预览不显示删除，快捷入口不显示操作按钮提示。

普通结果的长标题、路径和命令默认收起，选中后显示完整内容，也可用「展开内容」独立展开。快捷入口只显示图标与名称。剪贴板文本默认两行，选中显示五行，完整原文由「展开」查看；展开不改变打开、粘贴或复制所用的原始数据。超长普通内容保留显式展开入口，避免选择时一次插入过大的文本。虚拟列表通过 `ResizeObserver` 更新展开后的组高度，普通输入不增加同步测量。

覆盖各类型操作栏与动作分发、F6／⇧F6 焦点顺序、`Esc`／`Tab` 规则、组合输入期间不抢焦点，以及长列表窗口下的结果定位。真实 WKWebView 中的焦点环、Tab 顺序与输入法行为仍未人工验收。
