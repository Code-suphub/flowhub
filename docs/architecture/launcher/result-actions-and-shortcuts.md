# 结果操作、焦点顺序与快捷键

搜索窗口的短内容默认使用全宽紧凑结果列表，宽窗口选中长文本时自动展开独立详情区，也可手动切换预览。单击选中，已展开的预览随选择更新；窄窗口单击进入详情。双击或搜索框回车执行，鼠标悬停不改变选中项。复制等常用动作位于详情区，主动作位于底部，其余动作集中在可搜索的结果操作面板；工具保留全宽工作区。按钮和键盘共用 `runResultAction` 或对应工具处理逻辑。

## 预览布局

底部预览按钮和 `⌘I` 展开／收起详情，结果行的预览按钮始终打开对应项。宽窗口使用两栏布局，并在本机 `flowhub.search.previewExpanded` 中记住显式展开／收起偏好；只在初始化读取和用户切换时写入，不在输入路径访问存储。查询、范围及重新唤出不重置该偏好，工具或无结果临时收起详情也不覆盖偏好。预览关闭时不挂载正文和操作按钮，列表使用完整宽度。

“设置 → 搜索 → 长内容自动预览”对应 `core.autoPreviewLongContent`，未设置时默认开启。宽窗口选中超过 80 个字符或至少 3 行的剪贴板文本、命令备忘时自动展开；短内容保持紧凑，手动展开偏好仍优先。长文本直接检查长度，只有短文本需要计数换行，不进行 DOM 宽度测量或存储访问。自动展开保留搜索框焦点，不改写手动预览偏好，也不会复制或执行结果。

手动收起会抑制当前记录的自动预览，复制次数更新、后台刷新及仍匹配同一条的查询不会使其立即重开。切到其他记录后清除该临时抑制，再次选中长内容可自动展开。设置保存后通过现有配置事件更新启动器；自动预览关闭或内容变短导致正文卸载时，必要时恢复搜索框焦点，剪贴板编辑与确认弹窗继续由其自身管理焦点。关闭自动预览不禁用 `⌘I` 或行尾手动预览。

窄于 720px 时，预览是临时的详情页，范围与类型筛选在阅读时收起，为正文留出空间，返回列表时恢复。返回按钮、`⌘I` 或 Escape 回到列表，不写入宽窗口偏好；矮窗口使用紧凑页头和工具栏。缩窄窗口先显示列表，原焦点位于详情时回到搜索框；放宽后按已保存偏好恢复。展开／收起保留查询和选中项，显式收起也保留输入光标；浏览器只读演示的布局切换仅留在当前页面内存中，存储不可用时仍可使用。

仅在明确打开预览后、React 已提交详情 DOM 时安排聚焦。新输入、范围切换、收起、宽窄切换和卸载可取消待执行聚焦，不在普通结果更新后抢焦点。结果行的 memo 比较包含预览回调，避免宽窄切换后保留旧布局行为。

## 操作栏

| 结果类型 | 动作 |
| --- | --- |
| 网页 | 打开、复制链接 |
| 网页「添加到配置」 | 打开、复制链接 |
| 应用 | 打开、复制路径 |
| 备忘 | 复制命令、粘贴 |
| 2FA | 复制验证码 |
| 计算／时间戳／JWT | 复制结果 |
| DNS／IP | 复制查询命令 |
| ping／curl／端口等工具 | 工具自带按钮（执行、复制命令、复制输出、刷新、结束进程…） |
| 剪贴板记录 | 置顶、纯文本粘贴、编辑副本（见[剪贴板留存与操作](../clipboard/retention-and-actions.md)） |

没有可用动作的结果（例如纯提示行）不渲染空操作栏。

## 结果操作面板

底部“操作”、结果右键和 F6 操作链末尾打开同一个面板，显示结果类型及记录标题，输入框立即获得焦点。复用公共 `Dialog` 与 `CommandSearch`，输入按动作名称或中英文别名过滤（如“复制”“置顶”“copy”）；仅搜索当前结果的已有动作，不混入全局设置或插件命令。↑↓ 选择、回车或点击执行，筛选、高亮和清空搜索不执行。没有匹配时显示空态，可清空后继续选择；每次重开清空动作筛选，保留原搜索查询与选中项。

剪贴板依类型提供粘贴、复制全文／文件名、置顶／取消置顶、纯文本粘贴、编辑副本和删除确认入口，图片不显示文本操作。右侧快捷键表示搜索框内的原有快捷键，面板内部使用方向键与回车；浏览器只读预览的动作明确禁用且隐藏删除入口，控制器执行前再次检查只读状态。

面板以类型、ID、路径、URL 及快捷入口分组构成记录身份。后台重排时保持原对象和面板查询，执行时从控制器的最新结果按身份查找；目标消失则关闭，不能把操作落到原行号的新记录上。显式执行在面板卸载后分发，重复选择不会重复分发；重新唤出、新输入及卸载会取消未分发的动作。删除仍进入独立确认弹窗；复制失败／原生打开失败仍使用现有状态反馈与恢复流程。

公共弹窗管理焦点范围，面板打开时主体的范围快捷键、预览快捷键与剪贴板快捷键不穿透。组合输入、`229`／`Process` 及提交后 80ms 的回车不选动作；Escape、⌘K 或 F6 关闭面板并回到原搜索框，不同时退出其下方的窄窗详情。矮窗口列表独立滚动，搜索框和返回提示保持可见。

## 统一命令入口

头部“命令”或 `CommandOrControl+Shift+P` 打开 `CommandPalette`。通过公共 `CommandSearch` 查找搜索范围、主体设置页面、插件市场、已启用的独立插件和当前可用的窗口操作。中文／英文别名按名称优先排序，最多显示 60 项；索引仅包含入口元数据，不索引私人的剪贴板／目录正文，普通输入不访问数据库、磁盘或原生扫描。

设置页面及其别名复用设置导航定义，例如“主题”前往外观、“快捷键”前往通用设置；选中页面不自动更改设置或执行页面内按钮。搜索范围命令保留当前关键词；清空关键词需要明确选择“清除当前搜索”。预览与固定窗口命令根据当前能力与状态提供，固定操作在只读环境禁用。它与当前记录的操作面板分别使用明确的“命令”和“操作”入口，`⌘K` 保留返回搜索框。

打开面板时异步读取原生 `launcher_plugin_entries`，仅主搜索窗口可调用，仅返回已启用插件的 ID、名称和简介；不返回安装目录、可执行文件和权限。输入筛选使用内存列表，读取失败保留主体入口并提供重试。选择插件通过设置目标跳转到现有插件工作区，原有 `plugin_api` 管理来源校验保持不变。原生再次校验插件仍启用；卸载／停用后打开失败会保留面板与筛选，可重新选择或重试。

`open_settings` 的 `initialModule` 只接受固定主体页面或安全插件 ID，和添加网页的 `initialUrl` 互斥。新设置窗口通过 URL 加载目标，已有窗口通过有界等待调用 `switchModule`；设置尚未加载或正在忙碌时保留最后一次跳转，恢复可用后处理，已有 JSON／草稿保护继续适用。

两个启动器面板共用 `CommandDialog` 的输入法和按键隔离，并关闭通用弹窗的触发按钮自动恢复，由启动器在卸载后明确恢复搜索框焦点。确认、编辑或外部打开进行中不响应命令入口；面板内 Tab／范围键不影响底层搜索，新输入、重新唤出与卸载取消旧面板和待执行焦点操作。

## 搜索历史与补全

搜索框右侧历史图标、`CommandOrControl+Shift+H` 和统一命令入口中的“搜索历史与补全”打开 `QueryHistory`。面板复用公共弹窗与自动完成控件；当前关键词作为初始筛选，前缀优先，其余按最近使用顺序。选择只回填条件，不调用 `choose` 或结果动作；光标置于末尾，搜索结果仍需再次确认。原范围失效时界面提示并退到“全部”，剪贴板类型随查询恢复。来源变化时先清除旧结果再异步搜索，慢响应期间不允许快速回车执行旧列表。

`query-history.ts` 管理 `flowhub.search.queryHistory.v1`，只保存查询、范围、剪贴板类型、时间和随机 ID，不保存结果正文、应用路径或验证码。明确执行或复制结果触发记录；记录不保证动作成功，也不自动重试。相同条件更新时间并去重，最多 100 条，每条 256 字符；疑似凭据、多行／过长查询和 JWT／2FA／JSON 结果跳过。工具查询额外遵循原有命令历史开关。

`core.searchHistoryEnabled` 缺省开启，设置 → 搜索中可暂停新增；不影响已有历史的找回、移除与清空。历史管理独立于工具执行历史和参数模板，清空需要单独确认。浏览器只读模式不记录、移除或清空；存储失败时保留当前会话并提示。读取时检查数据形状、敏感内容及数量，丢弃额外字段和重复 ID。打开面板及 storage 事件刷新内存快照，记录／管理动作合并最新存储；普通输入路径不访问历史存储。新输入、重新唤出和卸载可取消尚未执行的回填与焦点操作。

## 焦点与 Escape

打开网页或应用时，原生主线程先隐藏启动器，再执行浏览器标签复用或应用启动；使用记录更新放在成功之后。等待期间暂停结果重绘和悬停选择，同一轮打开只提交一次。打开失败恢复原查询和选中项；用户已重新唤出或主动收起时，旧请求不能恢复、隐藏或覆盖新一轮窗口。

- 搜索框是默认焦点。普通结果的 `↑↓` 逐项移动；`Tab` 切换搜索范围（按住 `Tab` 再用方向键逐个切换）。仅在输入框值和当前查询都完全为空、焦点位于输入框且选中快捷入口时，无修饰键的 `←→` 在同排移动，到边界停留并更新记忆列；有文字、空格、待更新查询、操作按钮焦点或输入法组合输入时，左右键交给原控件。
- 空查询的全部、应用和网页范围同时显示「常用」「最近」两排紧凑入口，各自保留当前范围的数据；空组显示独立空态，不影响另一组。上下键跨排并保持选中列，鼠标选择更新记忆列；短排暂选末项，返回时恢复原列。空排跳过，最后一排向下进入首条普通结果，首条普通结果向上回到最后一排的记忆列；查询和范围变化重置记忆列。同一对象可在两个快捷入口组中各出现一次。
- `F6` 进入当前结果可用操作，再按 `F6` 向后、`⇧F6` 向前。有查询时先经过清除按钮，再经过可见的详情动作和底部主动作，末尾 F6 打开可搜索的操作面板，面板内 F6 回到搜索框；无结果时包含清除／搜索全部的恢复按钮。收起预览后跳过其动作，快捷入口也可以访问可用动作。
- 焦点在操作栏里时 `Tab` 交给浏览器的默认顺序，不再切换范围；`Esc` 每次只退出一层：操作面板、窄窗口详情、搜索框／窗口；关闭面板不同时关闭其下方的详情。退出详情动作回到搜索框并选中现有关键词。
- `⌘K` 在任何时候都回到搜索框；`⌘I` 展开／收起详情，长按不重复切换。详情内 `⌥↑`／`⌥↓` 只切换可预览结果，不执行、不修改查询，到边界停止。虚拟列表只在显式导航时定位目标，不在普通输入中读取布局。
- 键盘方向导航后使用键盘选中高亮；鼠标悬停、滚动或重绘不改变选中项和详情。明确点击或方向键才更新选择。
- 输入法组合输入期间（`isComposing`／`keyCode 229`／`Process`，以及回车提交后 80ms 内）以上快捷键都不生效，按键交给输入法；编辑剪贴板副本时键盘只归编辑框，`Esc` 取消编辑，`⌘↩` 保存。

## 快捷键说明

### 录入与跨平台格式

设置录入、别名比较和搜索范围键触发共用 `app/ui/shared/shortcuts.js`；React 通过类型适配层使用同一实现，搜索页直接加载该脚本。

- Command 录入为后台支持的 `Command`，macOS 界面显示 `⌘`。后台注册兼容旧配置中的 `Meta`／`OS`，无需用户重新录入；不会把不认识的键静默替换成默认快捷键。
- `Meta`、`Command`、`Cmd`、`Super` 使用相同的修饰键语义；`CommandOrControl` 的四种名称按当前平台解析，macOS 对应 Command，其他平台对应 Control。冲突检测与触发采用相同规则。
- 优先读取 `KeyboardEvent.code`，避免 Option 的特殊字符、Shift 的标点变化和输入布局改变存储的按键。保留数字小键盘及小键盘 Enter 的独立身份。没有 code 时仅接受可识别的兼容键名。
- 输入法组合中、重复事件和单独修饰键不会录入。macOS 全局注册器尚未支持的 F21–F24、媒体键会在录入时提示；范围键和其他平台按各自能力处理，不能据此保证所有硬件层 Fn 行为。
- 无修饰键的 Escape 取消录入，无修饰键的 Delete／Backspace 清空允许清空的范围键；带修饰键时按普通组合键录入。

底部说明由 React `KeyboardHint` 按当前选中结果和运行环境动态生成，只列真的可用的操作：非剪贴板结果不显示剪贴板快捷键，图片记录不显示纯文本粘贴与编辑副本，浏览器只读预览不显示删除。提示与底部主动作共用同一名称，工具结果不提示不存在的详情快捷键。

结果列表只显示标题、摘要和图标；全部范围额外标明来源，单一范围不重复来源标签。关键词按字面匹配高亮，限制搜索词长度、数量和每字段标记次数；不插入 HTML、不扫描完整长剪贴板内容。

长标题、路径、多行命令及剪贴板原文在独立详情区阅读，不改变列表行高。长文本预览有长度上限，复制／粘贴仍使用完整原文；显式切换对象后重置详情滚动。窄于 720px 时列表和详情分开显示，返回按钮或 Esc 回到列表，输入新查询恢复列表。

无结果时提供清除查询和保留查询搜索全部范围的入口；复制等短状态反馈与键盘说明共用底部位置，不追加一行把列表顶起。
