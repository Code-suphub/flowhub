# 机器管理插件实现任务

> 历史实现记录：机器业务现已迁入同级仓库 `flowhub-plugins` 的 `plugins/machines` 目录，旧宿主内置实现及声明式市场入口已移除。当前架构、一次性宿主升级和安装方法见 [独立插件协议](plugin-runtime.md)；下文安装及测试记录描述迁移前版本。

目标：本机运行、通过系统 SSH 管理 Linux 主机，用公共 Git 仓库分发插件，不部署管理服务器。

命令执行记录保存到机器数据目录的 `commands.sqlite3`，按实例、状态查询全部记录，每页支持 20 / 50 / 100 条。详情按需读取；每条输出仍有原有大小上限。内存中的最近记录仅用于工作台与状态轮询，不再限制历史列表数量。启动后把未结束记录标记为“结果未知”，不推断远端任务已停止。采集记录仍单独展示，旧版本已经丢失的内存记录无法恢复。独立开发预览新增“生成分页示例”，只生成模拟数据，刷新后清空；桌面版数据重启后保留。

- [x] T1 声明式插件协议：内置安装包、HTTPS 仓库源、签名和版本校验、安装/停用/卸载/回退。
- [x] T2 原生服务：本地清单、SSH 别名导入、限并发执行、输出上限、超时、取消。
- [x] T3 机器工作台：分组搜索、基础指标、后台轮询、批量命令、会话记录、打开终端。
- [x] T4 验证与交付：安全边界测试、只读预览、交互检查、公共仓库打包说明。

首版插件是声明式能力包（manifest + 命令模板），机器页面和 SSH 执行器由宿主提供。不是任意 JS/Rust 热加载。安装插件不自动连接机器；添加清单后手动采集，后台监控需要单独开启。真实主机和凭据不进入公共仓库。

现有工作区包含搜索排序及设置页未提交改动；本次保留，只添加必要入口。

- `cd app && npm test`：完整 Rust、前端回归、浏览器只读与生产 CSP 检查通过。
- 新增 9 个 Rust 测试，验证签名包及篡改拒绝、权限/兼容性、参数边界、指标、输出截断、真实子进程退出码与双输出流、超时/取消、写入失败保持原配置。
- 新增 4 个 Node 测试，验证筛选与目标 ID、指标过期、输出转义、只读预览、打包字节保持与 HTTPS 限制。
- Playwright 实际点击验证只读页面；使用仅注入测试浏览器的适配层验证安装、添加、采集显示、命令模板、直接执行目标、输出展示、筛选以及 800px 宽度无页面溢出。没有将模拟测试称为真实 SSH 验证。

远程命令点击“执行命令”后直接提交，不再弹出审阅确认。没有模板时隐藏模板入口；有模板时可选填预设命令。执行期间防止重复提交，保留目标数量与命令字节数校验。回归测试覆盖直接提交、刷新期间防重、空模板隐藏及模板填充。
- 已构建并安装本机 `/Applications/FlowHub.app`；没有连接真实主机、修改用户 SSH 配置、创建远程公共仓库或发布版本。

## 后续可扩展范围

已追加图形化本机 SSH 配置：地址、用户、端口、私钥路径和跳板机别名；通过 `~/.ssh/flowhub.d/*.conf` 与主配置 Include 统一。保存保留原文、创建备份、限制文件权限并检测外部修改。当前表单可单独进行 20 秒 SSH 认证与固定命令探测。新增原生测试在临时目录验证真实 `ssh -G` 解析、优先级、原文保留、冲突拒绝及配置注入拒绝。表单读取/探测/保存交互使用临时模拟页面检查，测试文件已移除，没有写入用户 SSH 配置或连接真实主机。

已追加本地开发安装：原生文件选择器读取 JSON 包，展示快照后安装；记录本地来源、支持同版本重新加载和回退，保持公共仓库验签边界。新增测试覆盖文件在审阅后变化、同版本重载、清单保留、来源持久化以及无效/超大文件拒绝。

SSH 导入是可选入口：仅点击扫描时读取主配置和 Include，显示来源与扫描反馈，勾选后加入管理。SSH 配置可能包含 Git 等用途，不能视为服务器清单；不会自动纳管或连接任何候选。点击别名查看实际配置，连接测试单独触发。添加机器不再提供重复的配置导入按钮；编辑普通 SSH 机器时自动加载连接配置，加载失败禁止保存并可重试，过期请求不能覆盖新表单。回归覆盖扫描不自动触发、按需读取/探测/纳管、编辑加载失败与过期响应，以及引号、通配 Include、循环、重复别名、大文件和缺失配置。

持久化趋势与告警、内嵌终端、跨设备配置同步和通用第三方 UI 插件不属于这一版。运行和仓库发布流程见 `plugins/README.md`。

已集成到设置窗口并拆分为独立插件市场：固定保留「插件市场」入口，市场支持目录扫描、检索、安装、更新、停用、卸载和回退；安装并启用后才显示「机器管理」，停用或卸载后移除。机器页面不包含安装和来源配置。页面按需加载宿主随附的同源界面，通过设置窗口调用原生服务。新增回归覆盖目录发现/变更/删除/符号链接、版本比较、审阅安装和停用卸载后的导航状态。
