# 端口与进程工具

在全部/工具可用搜索范围输入 `port 9000` 或 `端口 9000`。端口范围 1–65535。

- macOS 本机查询 TCP LISTEN 与 UDP 本地绑定，包括 IPv4 / IPv6。
- 显示名称、PID、用户、可执行路径、启动时间（本机时区）、运行时长和绑定地址。
- 不是全连接抓取：不会把远端目的端口相同的连接当成本地占用。
- 查询可见性受当前用户权限限制；未发现记录不保证其他用户没有占用。
- 普通回车复制进程详情；按钮可复制 macOS/Linux 查询命令。F6 聚焦操作按钮，Tab 在按钮之间移动。
- Linux 命令在目标主机执行，使用 ss、ps 等工具。sudo 可能要求现场授权。复制动作不会连接堡垒机或执行命令。
- IP 归属地、DNS、本机公网 IP 结果也提供查询命令复制（curl/dig）。“本机 IP”当前服务查询的是公网出口地址，不是网卡内网地址。

## 结束进程

点击指定 PID 的结束按钮，再在卡片里确认。后端重新查询端口，核对 PID、启动时间、用户名和程序路径生成的身份指纹，然后发送 SIGTERM。不使用 shell、不请求管理员权限、不自动发送 SIGKILL，也不能结束 FlowHub 自身或 PID 1。
SIGTERM 发送成功不等于进程已退出；工具会重新查询，也可点击刷新。macOS 传统 PID 信号接口无法提供 pidfd 级别的原子身份保证，复核用于降低 PID 复用风险。

## 架构

`tool-registry.js` 注册内置工具的识别/建议、可选渲染、查询生命周期、选择及动作处理。`port-tool.js` 封装端口工具状态、命令生成与确认 UI；Rust `port_inspector.rs` 独立负责受控本机操作。设置里的 port 开关可启停工具。

这不是外部插件热加载：工具代码随应用发布。既有 IP/DNS 等建议入口已走注册表，但其查询/渲染仍有旧代码留在 search.js，后续可逐个迁移为独立模块。当前规模下无需引入任意第三方 JS/Rust 动态执行；若将来开放第三方插件，需另行设计 manifest、版本兼容、权限和生命周期。

## 验证

```sh
cargo test --manifest-path app/src-tauri/Cargo.toml port_inspector --lib
node app/scripts/port-tool.test.cjs
```

Rust 测试使用自建临时 TCP+UDP 监听子进程，验证启动时间、双协议、错误身份拒绝以及正确身份 SIGTERM；只终止测试自身创建的子进程。JS 测试覆盖输入范围和注入拒绝、确认/取消、复制命令、禁用开关。浏览器使用合成进程数据验证结果卡片和操作；两份复制命令均通过 sh -n，未连接或验证真实堡垒机。

### 公网 IP 直接查询

输入 `ip` / `本机 ip` / `公网 ip` 自动显示统一结果卡，可刷新、分别复制地址、复制 macOS/Linux 查询命令。IPv4/IPv6 并发查询，每项最多 6 秒，先完成的地址先显示；失败不会被误报为没有配置该协议。不再等待归属地查询。卡片明确显示服务观察到的公网出口，代理可能改变结果。

公共查询 helper `public-ip.js` 供桌面/浏览器 adapter 共享；结果交互迁移到 `local-ip-tool.js` 注册模块。`node app/scripts/local-ip-tool.test.cjs` 验证部分成功、渐进返回、旧响应丢弃和复制。浏览器合成地址验证卡片布局；未将合成测试当作真实网络验证。

### 查询负载优化

同端口并发刷新共用正在进行的检查；不缓存结束进程前的身份复核。原生 ps 改为每批 128 个 PID 读取一次 lstart/etime/comm，保留路径中的空格并跳过已经退出的进程。IP 的输入切换/刷新主动取消旧 fetch；ipify 失败时按地址族回退到 4.ident.me / 6.ident.me，每次 3 秒，地址族总等待约 6 秒。未消除 macOS PID 信号固有竞态。
