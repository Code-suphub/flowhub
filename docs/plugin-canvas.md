# 桌面组件画布

从插件市场点击“桌面组件”，或使用插件原有的桌面监控入口。FlowHub 使用同一个 `plugin-canvas` 透明窗口展示多个插件的卡片，不再提供独立的工作台管理页面。

点击卡片打开所属插件页面；右键菜单编辑名称、来源和目标，也可移到下一行、并入上一行或移除。键盘 Enter 打开，Shift+F10 打开菜单。拖动标题调整顺序，拖到下方空白处另起一行，右下角手柄自由缩放。宽度为 160–1600 px，高度为 120–1200 px；窄窗口会限制可见宽度，保留原始尺寸。缩放手柄支持方向键每次微调 10 px，编辑布局模式提供前移/后移按钮。名称、目标、顺序、换行、像素尺寸、置顶保存在 `plugin-canvas.json`，不修改插件业务配置。已有多个布局仍可从工具栏切换，不丢弃卡片。浏览器预览使用明确标注的模拟数据和 localStorage。工具栏保持可见，避免编辑入口难以发现。

## 插件接入

单机卡片点击打开独立的监控详情窗口，默认展示负载历史，可切换 CPU、内存、磁盘、上下行速率、运行时间与时间范围。详情通过只读 `status_history` 插件协议取得 `{labels,data,unit}`，请求为 `{row,metric,seconds}`。宿主限定详情窗口和指标范围，不开放通用插件 RPC。缺失采样不连线。机器插件从本地 SQLite 提供数据，不依赖 FlowHub 设置主页面。

移动、缩放或移除卡片后，整个布局先向左、再向上收紧，其他卡片自动填补空位。收紧过程保持卡片之间的相对阻挡关系，不穿过或重叠相邻卡片；已有布局中的空洞也会在加载时消除。

布局现在保存每张卡片的 x/y 坐标。拖动任意卡片区域时可改变方向，松手选择最近的不重叠贴边位置，间距为 10 px。旧的固定换行不再限制并排；原有尺寸保留。宿主窗口按卡片范围收紧，拖至右侧或底部边缘时扩展，最大受当前屏幕尺寸限制。超出屏幕的布局可滚动查看。编辑弹窗打开时临时扩大窗口，关闭后恢复组件范围。

插件声明 `statusSurface: true`，并通过已有的 `status_snapshot` 返回状态缓存。宿主发现所有已启用的状态插件，提供组件选择器，不将机器采集代码移入宿主。

```json
{"title":"插件名称","rows":[{"id":"stable-id","name":"显示名称","status":"healthy","at":1790000000000,"values":{"cpu":12,"memory":36}}]}
```

状态支持 `healthy`、`error`、`stale`、`unknown`。`values` 中的数值按字段显示；CPU、内存、磁盘有百分比标签。未启用或卸载的插件保留布局并显示不可用。当前组件是宿主渲染的状态卡片，不加载第三方 HTML/脚本；尚未接入状态接口的插件不会自动出现。

画布只读取已有状态缓存，不启动额外的远程采集。刷新间隔 15 秒，编辑布局或弹窗打开时暂停界面重绘。菜单栏摘要继续沿用插件状态接口。
